Choose the destination first

A file extension is not the whole story

  1. 01

    Select the media family

    Use Image for a still picture, Video for a moving clip, or Audio for a sound file. GIF animation belongs in Video mode; Image mode exports a single frame.

  2. 02

    Choose the receiving app’s format

    Check what the destination accepts. A video container such as MP4 also holds particular codecs, so a matching extension alone does not guarantee playback.

  3. 03

    Review available controls

    Quality means different things for images, video and audio. Video can retain or omit sound; GIF has no audio. Explicit image/audio metadata stripping is a Premium option.

  4. 04

    Convert and test the result

    Save the export and open it in the actual destination. Keep the source: re-encoding cannot restore lost detail or sound information.

Three media families, three trade-offs

Conversion cannot invent source quality

Image quality

JPEG and WebP settings affect lossy encoding. PNG does not use that quality scale. A transparency-to-JPG conversion uses a white background in PMW.

Video quality

The slider changes encoding choices; it is not a file-size percentage. GIF output uses 8/12/18 fps and 480/720/1080px width tiers, so converting a video to GIF changes more than its extension.

Audio quality

Higher bitrate can produce a larger lossy file. Converting an MP3 to WAV or FLAC does not recreate sounds the MP3 already discarded. Keep a high-quality source for later editing.

Two choices behind a video file

The container is the box. The codecs are what is inside.

Understanding the export

An MP4 filename does not tell the whole story.

A video container packages tracks together, while codecs describe how the picture and sound are encoded. In PMW’s MP4 export, the picture uses H.264 and the audio uses AAC when sound is included. The container is MP4; H.264 and AAC are not alternative file extensions for the same thing.

That distinction matters when an upload form says “MP4” but also specifies a supported video codec. Two files ending in .mp4 can contain different encodings, so renaming a file does not fix a compatibility problem.

The format table above lists this tool’s current output combinations. Pick the one your destination accepts, then open the completed export there. A MOV export here also uses H.264 and AAC; choosing MOV does not turn it into a ProRes editing master.

Make the format serve the next step

Three practical conversion routes

01
Image workflow

A transparent graphic for a web layout.

Use Image mode and choose PNG or WebP when the receiving app supports alpha. A JPG output cannot keep transparency and uses a white background here. Inspect the edge on the intended page background. If you need specific dimensions, prepare a resized copy before choosing the final format.

Check transparency → choose PNG/WebP → inspect edges

02
Video workflow

A short clip for a player or a looping animation.

MP4 is a useful starting choice when the player accepts H.264/AAC. Keep audio enabled if sound matters. For a GIF loop, expect no sound and a reduced frame rate or width depending on the quality tier. Choose Video mode for moving GIF input; Image mode exports a still frame.

Check the player → choose MP4 or GIF → inspect motion and sound

03
Audio workflow

An editing copy or a smaller listening copy.

Choose WAV when the editor requests 16-bit PCM, or MP3/M4A when a compatible player needs a compact listening file. Re-encoding a lossy recording cannot recover discarded sound. Archive a suitable original, and listen to the completed copy before deleting or sharing anything.

Check the editor/player → choose WAV or a lossy format → listen

What an extension cannot promise

Four conversion misconceptions

01 · Re-encoding

A new extension is not a quality upgrade.

An MP3 exported to FLAC remains limited by the MP3 source. A small image exported to TIFF does not gain new detail. Choose the output for compatibility, not because its name sounds more professional.

02 · Size

A converted file can be larger.

Uncompressed audio, palette animation and lossless image encoding can produce more bytes than the input. The quality slider is not a target-size control. Keep the result only when its format and size suit the destination.

03 · Structure

Raster export is not a project archive.

Image outputs do not promise to preserve layers, multiple pages, every color profile or editing instructions. Keep an original project file in the app that created it when those properties matter.

04 · Device

On-device processing still needs resources.

Large media can use significant memory and take time, particularly on a phone. Leave the tab open and allow the engine to load. A smaller representative copy is useful when a full-length file exceeds practical device limits.

Formats are a choice, not a guarantee

Conversion questions answered

Can I just rename the extension?

Renaming changes the label, not the encoded contents. A real conversion decodes and exports to another supported format.

Why does my GIF stop moving?

Image mode exports one frame. Use Video mode with a GIF input to retain a moving sequence, and remember that GIF output has no sound.

Why is the first conversion slower?

Advanced formats and audio/video load the on-device media engine on first use. Processing then depends on the clip, settings and your device. Keep the tab open until the result is ready.

Can it convert every file with these extensions?

No. The input must be readable by the browser or bundled media engine. Unusual codecs, corrupt files, protected media and unlisted formats can fail even if the name looks familiar.

Will metadata be preserved?

Re-encoding can change or omit metadata even when explicit stripping is off. Image/audio stripping is a Premium control; inspect the exported file if metadata matters. It is not a guarantee to preserve every tag, layer or color profile.

What are the file and daily limits?

The current per-file limits are 100MB for images and 200MB for video/audio. Free access includes 13 successful file conversions per day; each file in a queue counts separately. Available device memory can impose lower practical limits.

Does my media leave the device?

File processing runs locally in the browser, including the media engine. The page fetches its code and can make normal analytics requests, but this conversion path does not upload your file contents to PMW. Download the result before closing the tab.
