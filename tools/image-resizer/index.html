A square is a different shape

Proportional resize versus stretching

A resize is not an automatic crop.

PMW draws the whole image into the requested dimensions. A crop removes part of the image; padding adds space around it. This resizer does not provide those separate modes.

For a different screen shape, prepare a crop in an image editor first, or choose wallpaper artwork with a matching orientation.

Size is only one part of the export

Keep detail, format and transparency in view

Avoid unnecessary upscaling

If your source is 941 × 1672, creating 1080 × 1920 interpolates pixels. It changes the file dimensions but does not reveal detail that was absent in the source.

Choose an appropriate format

PNG preserves transparency and sharp graphic edges. JPG uses a white background for transparent areas in this tool. WebP can retain alpha when supported. The PNG quality slider is hidden because it does not work like JPEG quality.

Think in pixels for print

An 1800 × 1200 image printed at 300 pixels per inch is 6 × 4 inches. This page changes pixels, not a print-DPI setting; your print software decides the physical size and quality.

Width × height tells a useful story

Half the width is a quarter of the pixels

A worked 16:9 example

960 × 540 is not half of 1920 × 1080 in pixel count.

A 1920 × 1080 image contains 2,073,600 pixels. Reduce both dimensions by half and the 960 × 540 copy contains 518,400 pixels: one quarter of the source pixel count, with the same 16:9 proportions.

This explains why choosing appropriate dimensions can help with web delivery. It does not predict a 75% reduction in file size. The format, encoding settings and the detail inside the picture determine how many bytes those pixels need.

For a 480-pixel-wide display slot, you might prepare a 960-pixel-wide copy for a two-times pixel-density screen when your source is large enough. The layout and device decide whether those extra pixels are useful. Avoid making every small preview as large as the original.

The destination sets the dimensions

Three ways to plan a resize

01
For the web

Start with the displayed slot.

Find the approximate width the image will occupy, then consider whether a higher-density version is useful. Keep its original ratio unless the layout specifically requires a crop. Review the file size after export; a large PNG and a JPG of the same dimensions can have very different byte sizes.

Display slot → proportional dimensions → inspect file size

02
For a wallpaper

Match the artwork’s shape to the screen.

A phone and a desktop usually need different orientations. Resizing a portrait into landscape does not add scenery to the sides; it stretches the source in this tool. Choose suitable artwork or prepare a crop elsewhere. Your device’s fill/fit setting can still change how the picture appears.

Screen orientation → matching artwork → suitable pixel frame

03
For a print

Calculate from physical size, then check the source.

A 6 × 4 inch print at 300 pixels per inch requires 1800 × 1200 pixels. This is an arithmetic example, not a universal print requirement. Ask the printer what it needs. If the source is smaller, increasing the numbers cannot restore missing detail.

Print size × requested pixels per inch → required pixels

Before the final download

Check the four parts of a good resize

01 · Shape

Does the subject still look natural?

Check faces, circles and familiar objects. If they look wider or taller, compare the source and target ratios. Re-enable the aspect lock and enter one dimension manually.

02 · Detail

Are you enlarging or reducing?

Small text can disappear when you reduce the frame. Enlarging can soften edges without adding information. View the export at its intended size rather than relying only on a zoomed-out thumbnail.

03 · Background

Is transparency still appropriate?

JPG output fills transparent areas with white here. Choose PNG or supported WebP if an overlay needs transparency. Check the edge against the background where the image will actually be placed.

04 · Delivery

Does the destination accept the copy?

Confirm the requested dimensions, accepted format and file-size limit. Keep the original and use a descriptive export filename so you can distinguish the resized version later.

Before you export

Resizing questions answered

Why does the image look stretched?

The target ratio differs from the original. Enable keep aspect ratio and edit one dimension manually, or prepare a crop before uploading. A preset is not an automatic crop.

Will resizing to 4K make it sharper?

It creates a 4K-sized file, not new source detail. Upscaling estimates new pixels from existing ones. A suitable original is the better starting point.

Does resizing guarantee a smaller file?

No. Pixel count, output format, encoding settings and content all matter. Use the Compressor when a byte limit is your main constraint.

What can I resize on the free plan?

The current allowance is 13 resizes per day, one image at a time, up to 10MB per input. Free output limits are width up to 3840, height up to 2160 and up to 8,294,400 pixels. Both dimensions matter, including for tall portraits.

How do batches handle aspect ratio?

The width and height are shared across the batch, and the manual aspect calculation uses the first image. Review mixed-orientation batches carefully rather than assuming every image will keep its own ratio.

Are my files uploaded or kept?

Resizing and export happen locally in the browser. PMW does not receive the file contents through this tool. Ordinary page/library/analytics requests still occur. Save the result before closing the page.
